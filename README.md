# Kho Từ TOEIC

Trang học từ vựng TOEIC, dữ liệu lấy từ các học phần Quizlet của lớp "Lớp TOEIC Online" (cô Tịnh).

- `vocab.json`: 199 học phần, 6.580 thẻ (`[{id, title, cards: [[thuật ngữ, định nghĩa], ...]}]`)
- `index.html`: thẻ ghi nhớ, trắc nghiệm A–D, gõ từ, danh sách, tìm kiếm, đánh dấu "đã thuộc" (lưu trên trình duyệt), phát âm tiếng Anh.

Chạy cục bộ: `python3 -m http.server` rồi mở http://localhost:8000
